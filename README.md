# Project Name: Rinterio

**Live Link:**  https://asifahmed1810.github.io/programming-hero-assignment-3/

DecoSpace is an interior design website offering inspiration, consultation, and tools to help users design their dream spaces. The platform includes a curated gallery, design tips, and 3D space visualization features.

## Technologies Used
- React  
- Tailwind CSS    
- FontAwesome  

## Key Features
1. **Interactive Design Gallery**  
   Explore a variety of interior design inspirations with detailed descriptions.  

2. **3D Room Visualizer**  
   Users can visualize their rooms with selected furniture and designs in 3D.  

3. **Responsive, Aesthetic Interface**  
   A visually stunning and fully responsive design to engage users on all devices.
